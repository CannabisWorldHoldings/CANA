# Phase B Slice 2 architecture

```text
owner maintenance CLI
  -> fixed ABCA adapter and bounded transport
  -> append-only acquisition/capability/circuit events
  -> immutable content artifact
  -> tenant compiler (UNKNOWN only)
  -> independent acquisition-bound Verification Court
  -> current compatibility projection
  -> ASK Answerability Frontier
  -> deduplicated Opportunity and bounded continuation
  -> owner-run acquisition plus court revalidation
  -> REFLECTION_ONLY receipt
```

The runtime product never imports live acquisition modules. Content identity, acquisition identity, truth eligibility, demand, and cognitive reflection are separate authority planes.
