# Truth write/read map

| Surface | Writes | Reads | Authority ceiling |
|---|---|---|---|
| Snapshot capture | New fixture directory only | Public DCGIS Layer 31, explicit owner invocation | Evidence acquisition; no verification |
| Reality compiler | One reusable immutable snapshot, tenant-scoped compilation, observations, resolutions, UNKNOWN claims, evidence, and explicit contradiction rows | Verified committed fixture and existing exact licenses/linked aliases | No retailer creation, court event, public eligibility, or current truth |
| Verification Court | Verification event and new claim state version | Stored raw bytes, observations, resolution, claim evidence, explicit clock | Predicate-scoped verification only |
| Compatibility projection | Existing Retailer truth envelope; linked operating-status GeoClaim | Complete approved claim cohort for the policy-owned public tenant | Current fields supported by that cohort only; other tenants cannot project globally |
| Evidence-labeled catalog discovery | None | Explicitly labeled demonstration product/deal candidates where the caller opts in | Candidate visibility only; retailer truth remains strict |
| Public assertion policy | None | Canonical `VERIFIED_CURRENT`, verifiedAt, freshness, non-demo predicate, post-query recheck | Read-only truth exclusion |
| Public map | None | Eligible verified/supported fresh GeoClaims | Allowlisted map predicates only |
| ASK route | Opportunity, mission, trigger, intent signal | Same current retailer truth gate | OBSERVE_ONLY work creation |
| MARKET_GAP consumer | Closure status and hash-chained REFLECTED receipt | A verified durable FIRED receipt, exact trigger/mission/tenant/tick binding, tenant-scoped opportunity/intent, and current truth query | No merchant, claim, provider, or publication write |
| Site Intelligence | Site snapshot plus observations/audit | Aggregate persisted truth/work counts | Read-only analysis; commercial action blocked |
| Cognitive reflection | Deterministic receipt value | One bounded episode and exact hashes | REFLECTION_ONLY, VALUE_NOT_ESTABLISHED, OWNER_REVIEW |

Public consumers do not query parser output. The compatibility layer exists so current APIs can remain stable while constitutional evidence becomes canonical.
