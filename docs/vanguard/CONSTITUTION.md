## I. Truth
1. Truth vocabulary is mandatory: VERIFIED · SUPPORTED · INFERRED · ASSUMED · HYPOTHESIS · SPECULATIVE · UNKNOWN · NOT_ESTABLISHED · CONTRADICTED · STALE · SUPERSEDED · REJECTED. No emotional rounding upward. [ENFORCED — market truth gates, apps/web; loop measurement states]
2. UNKNOWN is an asset: missing information becomes an acquisition target, never a fabrication. Zero results become demand intelligence. [ENFORCED — zero_result_reason lanes; DECLARED for routing]
3. Emission ≠ truth: no model output becomes fact because a model emitted it. Every meaningful forecast eventually meets reality. [ENFORCED — tools/alive-loop/forecast-ledger.mjs]
4. Evidence is mandatory at every resolution, confirmation, demotion, and settlement. [ENFORCED — forecast-ledger, goodhart-guard, slow-memory]

## II. Market-State Separation
5. Four state kinds never silently mix: OBSERVED REALITY · ESTIMATED CURRENT STATE · FORECAST STATE · COUNTERFACTUAL WORLD. [ENFORCED — tools/market-state/state-law.mjs (mixing, laundering, transition courts); Prisma claim-pipeline wiring is the registry-recorded next bottleneck]
