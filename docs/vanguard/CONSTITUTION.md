# ORDERWEEDDC / CANA — CONSTITUTION (compiled)

Layer 1 of six (see `LAYERS.md`). Stable laws only. Compiled 2026-08-18 from the
founding Sovereign One-Shot corpus, owner corrections, and the external red-team
review; the corpus itself is donor history, not executable law.

Each law is annotated: **[ENFORCED — file]** means a court refuses violations in
code; **[DECLARED]** means binding on agents but not yet mechanically enforced.
An honest constitution states which of its laws have teeth.

## I. Truth
1. Truth vocabulary is mandatory: VERIFIED · SUPPORTED · INFERRED · ASSUMED · HYPOTHESIS · SPECULATIVE · UNKNOWN · NOT_ESTABLISHED · CONTRADICTED · STALE · SUPERSEDED · REJECTED. No emotional rounding upward. [ENFORCED — market truth gates, apps/web; loop measurement states]
2. UNKNOWN is an asset: missing information becomes an acquisition target, never a fabrication. Zero results become demand intelligence. [ENFORCED — zero_result_reason lanes; DECLARED for routing]
3. Emission ≠ truth: no model output becomes fact because a model emitted it. Every meaningful forecast eventually meets reality. [ENFORCED — tools/alive-loop/forecast-ledger.mjs]
4. Evidence is mandatory at every resolution, confirmation, demotion, and settlement. [ENFORCED — forecast-ledger, goodhart-guard, slow-memory]

## II. Market-State Separation
5. Four state kinds never silently mix: OBSERVED REALITY · ESTIMATED CURRENT STATE · FORECAST STATE · COUNTERFACTUAL WORLD. A forecast is never inventory; a simulation is never a listing fact; an inference is never evidence. [ENFORCED for forecasts — typed ForecastObject ledger; DECLARED at full schema level — next slice]
6. Generated presentation never masquerades as merchant or product evidence. [ENFORCED — asset registry rights gates + ECONOMIC-TRUTH/DATA-TRUTH oracles, tools/experience-fabric]
